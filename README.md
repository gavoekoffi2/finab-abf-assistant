# FINAB ABF Assistant

Assistant privé pour préremplir l'ABF Greatway à partir d'un formulaire prospect intégré, avec révision obligatoire du conseiller financier avant génération finale.

## Principe clé

Le PDF ABF final doit rester le formulaire officiel Greatway original : même mise en page, mêmes couleurs, mêmes pages, mêmes champs. Le moteur remplit les champs AcroForm existants au lieu de reconstruire le PDF.
